# Lost & Found

A web-based **Lost & Found Management System** designed to help users report, browse, and manage lost and found items in an organized way.

## 📌 About the Project

The Lost & Found system provides a centralized platform where users can report lost or found items and view available listings. The project focuses on making it easier to connect people with their missing belongings while keeping item information organized.

This project was developed as a **university software engineering project**.

## ✨ Features

* Report lost items
* Report found items
* Browse listed items
* View item details
* Search and manage lost & found records
* Update item status
* Organized and user-friendly interface

## 🛠️ Technologies Used

* **C++**
* **CMake**
* **HTML / CSS / JavaScript** — for the web interface
* **Git & GitHub** — version control and collaboration

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/alihaa-eimann/Lost-and-Found.git
```

### 2. Open the project

Open the project in an IDE such as **CLion** or another C++ development environment that supports CMake.

### 3. Build the project

Make sure **CMake** and a suitable **C++ compiler** are installed and configured.

Build the project using your IDE or CMake.

### 4. Run the application

Run the generated application/server according to the project configuration.
